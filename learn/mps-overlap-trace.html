Step 0 — foundation

What "axis" means

An array's shape is a list of its dimensions. A 2-D array has two of them, numbered starting at 0. Axis 0 moves down through the rows. Axis 1 moves across the columns. Every tensordot call is really just: "pick an axis on the first array, pick an axis on the same size on the second, multiply matching entries along it, and add them up."

This example array has shape (2, 3): 2 positions along axis 0, 3 along axis 1. When two arrays share a matching axis size, tensordot can contract (sum over) that pair of axes — that's the entire mechanism behind everything below.

Step 2 — where A₀, A₁, B₀*, B₁* actually come from

Naming things before using them

First, about the shape of ψ. Above, ψ is written as [0.7071, 0, 0, 0.7071] — that's just how a flat Python list prints, with commas, left to right. It is not a "1×4 row" or a "4×1 column" — those are both 2-dimensional shapes, and ψ starts out as neither. In code it's a plain 1-dimensional list of 4 numbers, shape (4,) — no rows, no columns at all yet. Textbooks draw a quantum state as a column purely as a drawing habit; the code has no such thing until we deliberately create it. That happens on the very first real line of statevector_to_mps:

psishape (4,) — flat, no rows or columns .reshape(2, -1) [[0.7071, 0 ] [0, 0.7071]]shape (2, 2) — NOW it has rows and columns

Second, where the letters A and B come from. They're not part of your code at all — they're just labels this page uses. Running statevector_to_mps(psi, 2) returns a Python list with 2 entries; this page calls those entries A₀ and A₁ (in your code, that's tensors_psi[0] and tensors_psi[1]). Running the same function on φ gives tensors_phi[0] and tensors_phi[1], which this page calls B₀ and B₁ — and once conjugated (multiplied by np.conj inside mps_overlap), B₀* and B₁*. The star just means "conjugated," nothing else.

Third, "site." A site is just a position along the qubit chain — site 0 is qubit 0, site 1 is qubit 1. It's the same idea as the loop variable q back in statevector_to_mps, only now walking two chains (ψ's and φ's) at matching positions.

Fourth, "bond." When statevector_to_mps ran its SVD at each site, the number of singular values it kept became new_bond in the code — and that number is a real connection between one qubit's tensor and its neighbor's. This page calls that connection a bond. It's just one number: how many independent channels link two neighboring tensors. Nothing more mysterious than that.

Putting all four together — every one of A₀, A₁, B₀, B₁ has exactly 3 axes, always in this order:

example: A₁ = tensors_psi[1]
shape (2, 2, 1)
axis 0 = left bond, size 2 — the connection coming in from site 0  ·  axis 1 = physical, size 2 always — this qubit's own 0/1  ·  axis 2 = right bond, size 1 — there's no site 2, so this is a trivial placeholder connection
