Splitting and Cutting an MPS

A worked example with 3 qubits. We turn the W state into a chain of small tensors (an MPS, short for matrix product state), see what the links between them hold, and then cut a link to save memory. Every number on this page can be checked by hand.

Start

The state

|ψ⟩ = (1/√3) · ( |001⟩ + |010⟩ + |100⟩ )

Qubits are written q0 q1 q2 from left to right. So |001⟩ means q0 = 0, q1 = 0, q2 = 1.

  • Exactly one qubit is 1 in every term.
  • Each term has amplitude 1/√3 ≈ 0.577.
  • Square an amplitude to get a probability: 0.577² = 0.333, so each of the three outcomes happens 1/3 of the time.

Step 1

Group by q0

It's just like a SQL GROUP BY. Write each ket as "q0's part ⊗ the rest", then collect the terms by q0's value:

|001⟩ = |0⟩ ⊗ |01⟩
|010⟩ = |0⟩ ⊗ |10⟩
|100⟩ = |1⟩ ⊗ |00⟩

|ψ⟩ = (1/√3) · [ |0⟩ ⊗ ( |01⟩ + |10⟩ )   +   |1⟩ ⊗ |00⟩ ]
                 └──── group A ─────────┘     └ group B ┘

q0 has only two values, so there are two groups. Lay them out as a table: rows are the groups (q0's value), and columns are every value the remaining qubits q1 q2 can take.

q1q2 = 00011011
q0 = 000.5770.5770group A: |01⟩ + |10⟩
q0 = 10.577000group B: |00⟩

Why q0 is linked to the others

  • If q0 = 0, then q1 q2 is 01 or 10.
  • If q0 = 1, then q1 q2 is 00.

What q1 q2 can be depends on q0. The two rows are different, so q0 and the rest are tangled together. The link between q0 and q1 has to carry that information.

Importance numbers

For each row, add up the squares of its amplitudes:

group A (q0 = 0):  0.577² + 0.577² = 0.333 + 0.333 = 0.667
group B (q0 = 1):  0.577²                         = 0.333
                                           total  = 1.000

In this example each importance number is the probability of its group. They add up to 1 because the state is always in exactly one group.

Two non-zero importance numbers → the link has bond size 2. Bond size means the number of groups (or "roads") the link needs.

Step 2

q0's tensor

A tensor here is just a small table of numbers that belongs to one qubit. q0's tensor answers one question: "if q0 has this value, which group does it go to: A, B, or a mix of both?"

group Agroup B
q0 = 010
q0 = 101

The groups' contents go into a second table, the rest. It has the same numbers as Step 1, but its rows are now labelled by group instead of by q0:

q1q2 = 00011011
group A00.5770.5770
group B0.577000
[ q0's tensor ] ──link (A or B)── [ the rest: q1 q2 together ]
Here the numbers are clean 1s and 0s because the two rows in Step 1 used different columns. In messier states, q0 = 0 can go partly to A and partly to B, and the numbers are smaller than 1. That's what entanglement looks like inside a tensor. For q0, the first qubit, the tensor is 2 × (number of groups), so at most 2 × 2.

Nobody keeps a middle tensor's numbers in their head. The picture to keep is: a tensor sits between links and says which road to take next. The computer does the bookkeeping.

Check

Walk the chain: every amplitude comes back

Pick q0's road, go through q1's crossroads, then read q2:

|001⟩:  q0=0 → A  →  from A, q1=0 → C  (0.577)  →  from C, q2=1 → 1   =  0.577 ✓
|010⟩:  q0=0 → A  →  from A, q1=1 → D  (0.577)  →  from D, q2=0 → 1   =  0.577 ✓
|100⟩:  q0=1 → B  →  from B, q1=0 → D  (0.577)  →  from D, q2=0 → 1   =  0.577 ✓
|110⟩:  q0=1 → B  →  from B, q1=1 → nothing                           =  0     ✓

In this W state, every row picks exactly one road. In messier states a row can send you down both roads with different numbers. Then you follow both paths, multiply the numbers along each one, and add the results.

Steps 1–3 were splitting. Nothing was lost: the three small tensors hold the whole state exactly.

Step 4

Cutting: drop a road to save memory

Cutting means deliberately throwing away a road at a link. The state becomes smaller to store, but it's no longer exact.

Why cut?

  • Every road at a link costs memory.
  • 3 qubits: each link needs at most 2 roads.
  • 12 qubits (our hadron circuit): the middle link can need up to 64.
  • 60 qubits: the middle link can need up to about a billion.

So we set a cap: keep at most k roads per link, and keep the ones with the biggest importance numbers. In quimb this cap is max_bond.

Cut the W state to 1 road at the q0–q1 link

Road B was the only way to reach |100⟩, so that term disappears:

before:  (1/√3) · ( |001⟩ + |010⟩ + |100⟩ )      each amplitude 0.577
after:   (1/√2) · ( |001⟩ + |010⟩ )              each amplitude 0.707

The 0.577 becomes 0.707 so that the probabilities add up to 1 again. This rescaling is called re-normalising.

How much did we lose? Fidelity

Fidelity scores how close the cut state is to the original: 1 means identical and 0 means completely different. For one cut at one link:

fidelity = the sum of the importance numbers you kept
Here we kept road A, so fidelity = 0.667. We lost a third of the state.
  • Dropping big importance numbers hurts. The W state is a bad case.
  • Dropping tiny ones costs almost nothing. Keep 16 roads out of 64 and drop 48 that add up to only 0.00001, and the fidelity is still 0.99999.
When does the cut happen? TEBD builds the state one gate at a time, and quimb cuts after every gate whenever a link goes over the cap. Small losses add up over many gates, so the final fidelity can be lower than a single cut at the end would give.

Summary

Five things to remember

  1. A link is an SVD at that point in the chain. Its bond size is the number of non-zero singular values.
  2. Importance number = singular value², and they add up to 1.
  3. Cutting = dropping the tail of Σ (the smallest singular values).
  4. Fidelity after one cut = the sum of the importance numbers you kept.
  5. TEBD cuts after every gate, so small losses add up. This is the question for Phase 2 of the hadron work.
