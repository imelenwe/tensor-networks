The Electric Gate: a phase, not a move

Brick 18 worked by hand on two qubits. States are written |q0 q1⟩.

1. The gate

Brick 18 from brickwork_annotated.png.

In order: X(q0), Rz(θ)(q0), CX(q0 → q1), Rz(−θ)(q1), CX(q0 → q1), X(q0), Rz(θ)(q1). 2 CNOTs. Here θ = 0.005 (earlier circuit); 0.113 in the newer files.

The bits come back unchanged; only a phase was added.

3. All four inputs

input |q0 q1⟩output
|00⟩e−iθ/2 |00⟩
|01⟩e+3iθ/2 |01⟩
|10⟩e−iθ/2 |10⟩
|11⟩e−iθ/2 |11⟩

Checked by computer: the gate is diagonal (no bit ever changes).

Three configurations get the same phase; only |01⟩ is different, by e2iθ. A common phase does nothing, so the whole gate means: give the configuration |01⟩ of this site an extra phase 2θ — that configuration costs electric-field energy.

4. Applying it to a bigger state

No factoring needed: in every term, look at the (q0, q1) bits and multiply by the matching phase; q2, q3 ride along. On the state after the SWAP:

cos²θ' e^(−iθ/2) |0011⟩  − i sinθ' cosθ' e^(+3iθ/2) |0110⟩
− i sinθ' cosθ' e^(−iθ/2) |1001⟩  − sin²θ' e^(−iθ/2) |1100⟩

θ' = −0.15 is the pair-gate angle; θ is the electric angle. Only the |0110⟩ term (q0 q1 = 01) picks up the different phase.

Key points

  • 2 CNOTs; never changes bits or probabilities — phase only.
  • Only |01⟩ on the site gets a different phase (2θ): the energy of the electric field.
  • Phases matter at the next step: the pair gates mix terms and the phases decide which hops add up. A strong field makes stretching the string expensive, so quark and antiquark stay together (confinement). The newer circuit's field is 22× stronger.
